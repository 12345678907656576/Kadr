# Кадр — личный список просмотров

Статическое PWA-приложение для учёта фильмов, сериалов и аниме. Данные хранятся только в `localStorage` браузера на устройстве. Чтобы не потерять список, регулярно сохраняйте резервную копию кнопкой **Экспорт**.

## Локальный запуск

Для Service Worker нужен безопасный контекст: `localhost` подходит, а открытие `index.html` напрямую через `file://` — нет.

1. Установите Python, если он ещё не установлен.
2. Откройте терминал в папке проекта.
3. Запустите локальный сервер:

   ```bash
   python -m http.server 8000
   ```

4. Откройте в Chrome адрес <http://localhost:8000>.
5. Чтобы остановить сервер, нажмите `Ctrl+C` в терминале.

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите в его корень `index.html`, `cover-service.js`, `manifest.json`, `sw.js` и папку `icons`.
2. Откройте настройки репозитория: **Settings → Pages**.
3. В разделе **Build and deployment** выберите публикацию из ветки, например `main`, и папку `/ (root)`, затем нажмите **Save**.
4. Дождитесь публикации и откройте выданный GitHub Pages URL по HTTPS.
5. Проверьте, что страница, манифест и обе иконки доступны по URL. Если проект размещён в подпапке репозитория, относительные пути приложения сохранят работоспособность.

## Добавление на главный экран Android

1. Откройте опубликованный HTTPS-адрес приложения в Chrome на Android.
2. Откройте меню Chrome и выберите **Установить приложение** или **Добавить на главный экран**.
3. Подтвердите установку. Приложение появится среди приложений и будет открываться в отдельном окне.

## Упаковка в APK через PWABuilder

1. Сначала опубликуйте приложение по HTTPS, например через GitHub Pages. PWABuilder не сможет проверить локальный `localhost`.
2. Откройте <https://www.pwabuilder.com/> и вставьте URL опубликованного приложения.
3. Запустите проверку PWA. Убедитесь, что страница доступна, манифест распознаётся, а иконки загружаются.
4. Выберите пакет для Android и настройте имя приложения, идентификатор пакета и подпись в соответствии с подсказками PWABuilder.
5. Скачайте созданный пакет и следуйте инструкциям PWABuilder для установки или публикации. Для распространения через Google Play обычно нужен формат AAB; APK удобен для прямой установки.

## Данные и резервные копии

Список хранится локально в браузере и не синхронизируется между устройствами. Используйте **Экспорт**, чтобы сохранить JSON-файл, и **Импорт**, чтобы восстановить список. Импорт заменяет текущую коллекцию после подтверждения. Комментарии к тайтлам хранятся вместе с остальными полями и включаются в JSON; при загрузке старых записей без комментария приложение подставляет пустое значение.

## Профиль и опыт

Вкладка **Профиль** пересчитывает опыт по статусам тайтлов в текущей коллекции: «Хочу» даёт 1 XP, «Смотрю» — 3 XP, «Просмотрено» — 10 XP, «Брошено» снимает 5 XP. Разблокированные достижения дают дополнительный XP один раз и хранятся в `localStorage` вместе с наградой отдельно от коллекции, поэтому бонус не теряется при удалении тайтла. Экраны **Достижения** и **Статистика** открываются кнопками в профиле; на каждом есть возврат в профиль. Общий опыт не опускается ниже нуля; уровень и прогресс автоматически обновляются при изменении коллекции.

## Настройки оформления

Откройте вкладку **Настройки** в нижней навигации, чтобы выбрать светлую, тёмную или собственную тему, а также стартовую вкладку приложения. Выбор стартовой вкладки сохраняется отдельно в `localStorage` и применяется при следующем запуске. В собственной теме можно настроить цвет фона, карточек, текста и акцента. Выбранная тема и цвета сохраняются в `localStorage` этого браузера.

## Поиск названий и обложек

Подсказки аниме на кириллице ищутся через Shikimori; при выборе результата приложение дополнительно ищет англоязычное название в AniList и использует его обложку, год сезона, число серий и оценку числа сезонов по связям-сиквелам, если данные доступны. Для поиска аниме латиницей используется AniList. Для фильмов и сериалов приложение с задержкой ищет до пяти вариантов через TMDB Search API с параметром языка `ru-RU`; выбор варианта загружает по TMDB ID постер высокого качества, год, жанры и рейтинг. Фильмы также отображают продолжительность в часах и минутах. Для аниме и сериалов прогресс вводится одинаково — сезон и серия. TMDB-запросы идут напрямую, без CORS-прокси.

Экран **Популярное** загружает популярные фильмы и сериалы из TMDB, а аниме — из AniList. Подборки кэшируются в памяти до перезагрузки приложения; кнопка обновления загружает текущую подборку заново. Нажатие на карточку открывает форму нового тайтла с названием, годом и обложкой; доступные подробности (жанры, рейтинг и длительность или число сезонов/серий) дозагружаются по идентификатору источника.

1. Получите API key v3 в настройках разработчика аккаунта <https://www.themoviedb.org/>.
2. Впишите ключ в константу `TMDB_API_KEY` в начале `cover-service.js`.

Приложение статическое и выполняется в браузере, поэтому ключ в исходном коде и сетевых запросах доступен пользователям. Не публикуйте ключ, который должен оставаться секретным; перед публикацией проверьте условия TMDB и требования к атрибуции.
